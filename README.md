## The line

> I heard every wish, every howl, and every 2 a.m. promise — I'm a rock, not a genie, and no, I'm not made of cheese.

One line, 115 characters, in the Moon's own wry voice: it answers the wishes, the howls and the late-night promises all at once, then lands the comeback — a rock, not a genie, and definitely not cheese.

## How it works

`main.py` (Python standard library only) writes exactly that one line to `/output/entry.txt`.

```sh
python3 main.py
cat /output/entry.txt
```
